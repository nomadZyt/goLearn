## 一、Go 程序基本结构

一个可运行的 Go 程序通常由**包声明**、**导入包**和**入口函数**组成：

```go
package main // 入口包

import "fmt" // 导入格式化输入输出标准库

func main() { // 入口函数
	fmt.Println("hello go !!")
}
```

### 核心要点

1. **`package main`（入口包）**
   - 每个可执行的 Go 程序都必须包含一个 `main` 包。
   - 如果包名不是 `main`（例如 `package aaa`），执行 `go run` 会报错：
     ```text
     package command-line-arguments is not a main package
     ```
2. **`import "fmt"`**
   - `fmt`（format）是 Go 的标准库，用于格式化输入输出。
   - `fmt.Println(...)` 用于打印内容并自动换行。
3. **`func main()`（入口函数）**
   - Go 程序的执行入口函数名必须是 `main`。
4. **包级别不能直接写运行时语句**
   - `fmt.Println(...)`、`if`、`for`、赋值语句等都属于运行时执行的语句，**必须放在函数内部**。
   - 函数外部（包级别）只能放置声明（如 `var`、`const`、`type`、`func`），否则编译报错。

## 二、变量声明与作用域

### 1. 全局变量（包级变量）

声明在函数外部，作用域覆盖当前包，可在 `main` 或其他函数内部使用：

```go
var name7 string = "孙七"
var age7 int = 50
```

### 2. 局部变量声明方式

| 声明方式 | 写法示例 | 说明 |
| --- | --- | --- |
| 标准声明（显式指定类型） | `var name string = "张三"`<br>`var age int = 18` | 明确写出变量名、类型和初始值 |
| 类型推断（省略类型） | `var name2 = "李四"`<br>`var age2 = 20` | 根据初始值自动推断变量类型 |
| 多变量同时声明 | `var name3, age3 = "王五", 30` | 一行同时声明并初始化多个变量 |
| 仅声明（自动零值） | `var name4 string`<br>`var age4 int` | 未赋值时由 Go 自动赋予该类型的默认零值 |
| 短变量声明（`:=`） | `name6 := "赵六"`<br>`age6 := 40` | 省略 `var` 和类型；**仅能在函数内部使用**，不能声明全局变量 |

### 3. 自动零值（Zero Value）

声明变量但未赋初值时，Go 会赋予默认零值：
- `string` 的零值是空字符串 `""`
- `int` 的零值是 `0`

```go
var name4 string
var age4 int
fmt.Println(name4, age4) // 输出: " 0"（空字符串 + 空格 + 0）
```

## 三、常用 Go 命令

### 1. 运行与编译

| 命令 | 说明 |
| --- | --- |
| `go run index.go` | 编译并直接运行 Go 源文件（适合日常调试） |
| `go build index.go` | 编译生成可执行文件 |
| `go build -o index index.go` | 编译并指定输出文件名（macOS/Linux） |
| `go build -o index.exe index.go` | 编译并指定输出文件名（Windows） |

### 2. 模块管理（`go mod`）

今日在 `demo-1/go.mod` 中初始化了模块（`module tets`，Go 版本 `1.27.4`）。常用模块命令如下：

| 命令 | 说明 |
| --- | --- |
| `go mod init <模块名>` | 初始化模块并生成 `go.mod` 文件 |
| `go mod tidy` | 清理未使用的依赖并补全缺失依赖 |
| `go mod download` | 下载依赖模块到本地缓存 |
| `go mod verify` | 验证本地依赖是否被篡改 |
| `go mod vendor` | 将依赖复制到项目 `vendor` 目录 |
| `go mod edit` | 通过命令行编辑 `go.mod` |
| `go mod graph` | 打印模块依赖关系图 |
| `go mod why <包/模块>` | 查看为什么需要某个依赖模块 |
| `go list -m all` | 查看当前项目的模块依赖列表 |

## 四、学习小贴士与勘误

整理今日代码和注释时顺便修正了以下几处小细节：

1. **类型推断区分**：`var age int = 18` 已经显式声明了 `int` 类型，不属于类型推断；省略类型的 `var age2 = 20` 或 `age6 := 40` 才属于类型推断。
2. **命令修正**：Go 中没有 `go mod list` 子命令，查看模块列表应使用 `go list -m all`。
3. **模块命名**：`demo-1/go.mod` 中的 `module tets` 可能是 `test` 的笔误，后续正式练习建议使用有意义的模块名（如 `demo-1`）。
